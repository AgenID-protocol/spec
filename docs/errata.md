# Errata — AgenID v1.1.1

| ID | Date | Section | Summary | Status |
|---|---|---|---|---|
| E1 | 2026-09-13 | §5 | Number-domain rule was worded in terms of "integers" (implicitly Python `int` vs `float`) and was not implementable language-neutrally. Rewritten to be defined on the RFC 8785 **canonical token**: reject non-finite numbers, and reject integer-literal tokens (no `.`/`e`) with magnitude > 2^53−1. `1e21` ok, `1e20` rejected. No test vector changed. Discovered by the TypeScript reference implementation. | Applied in `spec/agenid-v1.1.1.md` |
| E2 | 2026-09-13 | §0.1, §6.2, §6.3, §9, §22 | Owner resolved the open `agenid.org` (standard) vs `agenid.com` (product) namespace decision (§22 item 1): unified on a single `agenid.com` namespace, no split. All normative schema `$id`s, the `.well-known` authority registry path, and the key-document API base URL moved from `agenid.org` to `agenid.com`. `manifest-proof` and `verification-assertion` sign the `$schema` member (§ "Crypto" decisions on record), so this changes signed bytes — §8 test vectors were regenerated from `vectors/generate_vectors.py` with the new domain and re-verified byte-for-byte and against all five JSON Schemas (CI green). | Applied in `spec/agenid-v1.1.1.md`, `schemas/*.json`, `vectors/generate_vectors.py`, `vectors/v1.1.1-vectors.json`, `README.md` |
